# LanguageGuard ecosystem governance

Canonical cross-repository governance for LanguageGuard / StudyGuard.

**Location:** `EnglishApp/.ai/ecosystem/` (this directory).  
**Host repository:** public `nguyenthaibinh19/EnglishApp`.  
**Status:** GOV-0B1 foundation — awaiting Leader review.

Other repositories should **link** here. Do not maintain independently editable copies of these global documents in Web or AI repos.

1. [ACTIVE_WORKSTREAM.md](ACTIVE_WORKSTREAM.md) — which stream is active and who leads it
2. [ECOSYSTEM_CHARTER.md](ECOSYSTEM_CHARTER.md) — roles and authority

## Source-of-truth notes

- Repo-local `.ai/` remains authoritative for that product’s implementation state.
- These ecosystem files are authoritative for **cross-repo governance**.
- They do not replace App ADRs, Website ADR-001, tests, or Git history.
- EnglishApp is public: keep this tree free of private Web ops detail, credentials, learner data, and private AI datasets.
